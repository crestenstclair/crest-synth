# Crest Synth

Crest Synth is a standalone, controller-first MIDI instrument host for Steam Deck and desktop.

[DESIGN.md](./DESIGN.md) is the single product and technical design. The [Figma redesign](https://www.figma.com/design/kdQMw8dYUZtv2UxJPo0sXU/Crest-Synth-%E2%80%94-Controller-First-UI-Redesign?node-id=0-1) is its visual and interaction reference.

The executable specification under `spec/` defines the implementation slice currently being generated. It must conform to the master design; it does not replace it. Repository SoundFont and MIDI fixtures support that slice and its integration proofs.

For contribution rules, see [CLAUDE.md](./CLAUDE.md).
