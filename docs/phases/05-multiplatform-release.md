# Phase 05 — Multi-Platform Release

Status: Deferred

## Outcome

Crest Synth can eventually ship beyond macOS, including Linux-based handheld
devices such as a Retroid Flip 2 running a flashed Linux environment.

## Scope

To be researched and specified when this phase is explicitly prioritized.

The eventual work is expected to cover platform composition, native input,
audio and MIDI backends, filesystem integration, packaging, installation, and
device-level acceptance without changing the canonical product architecture.

## Current decision

- The product is not intended to remain macOS-only.
- No platform research or implementation starts during the current phases.
- Earlier phases should continue respecting existing adapter boundaries and
  avoid unnecessary platform lock-in.

## Completion signals

To be defined after dedicated research. This document intentionally does not
pre-design the solution.
