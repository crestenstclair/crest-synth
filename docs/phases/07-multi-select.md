# Phase 07 — Multi-Select

Status: Deferred and not part of the current product

## Outcome

No current outcome is committed. The Select button remains reserved for a
possible future multi-select capability.

## Current decision

- Multi-select is not required for feature completeness.
- The reserved Select button does not imply implemented behavior.
- No accumulation, batch operation, cancellation, focus, or visual semantics
  should be invented during current work.
- The current product should truthfully expose multi-select as unavailable.

## Future scope

If this phase is ever prioritized, its product purpose and reducer semantics
must be designed before implementation begins.

## Completion signals

To be defined only if multi-select becomes an actual product requirement.
