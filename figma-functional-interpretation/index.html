What the Figma says Crest Synth is

A controller-first musical instrument organized around spatial memory, a tiny command grammar, and one stable editing shell—not a conventional desktop synth UI.

01 / Thesis

The product is the control grammar

The strongest design idea is not any engine, effect, or waveform. It is the promise that the same few physical actions mean the same thing everywhere, while the screen preserves the user’s location.

Crest Synth behaves like a hardware instrument rendered as text: focus moves spatially, Edit changes the thing under focus, and Shift changes the user’s depth or context.

The file repeatedly trades ornament for orientation. There are no card grids, tab bars, skeuomorphic knobs, or game-controller keycaps. Instead, hierarchy comes from fixed regions, hairlines, aligned values, color roles, and terse command hints.

02 / Product model

Two contexts, one stable shell

Figma encodes PATCH and MIXER as the only peer contexts. Everything else is a layer inside PATCH or a remembered location within one of those contexts.

Context and depth

The interface is shallow by design: switch context with Shift, then move through related surfaces without losing the originating row.

Sample Detail

Sample is treated as an instrument schema, but earns a specialized, non-focusable waveform because time landmarks need spatial feedback.

  • InferredVisualizations are admitted only when they clarify a control relationship; they do not become separate interaction regions.

Sample Browser

A controller-native file picker, not a generic operating-system dialog. The left side navigates; the right side explains and previews.

  • SeenRows distinguish parent, folder, file, and cancel using terse text markers.
  • StatedThe browser remains inside PATCH and returns to the exact Sample control that opened it.
  • InferredThe browser is designed as an instrument operation, not as global asset management.

06 / PEER CONTEXT

Mixer

A dense 16-track control field. Horizontal movement changes track; vertical movement changes the active control; the inspector expands the cursor into meaning.

  • SeenAll tracks remain visible; hairlines, not cards, preserve density.
  • StatedEdit adjusts or toggles; Select enters multi-select; Shift+Up returns to PATCH.
  • InferredThe focused channel is simultaneously highlighted in the field, named in the header/footer, and expanded in the inspector.

Choice states are full-list modals

Engine and post-FX selectors use the same 920×680 state frame: the current item is explicit, every available option is visible, Edit chooses, and Shift+Down closes. Figma shows concrete lists but does not state whether those lists are exhaustive.

05 / Interaction synthesis

Navigation is layered state

The interaction map is not a prototype. It is a design declaration: the same keys produce predictable movement across context, surface, focus, and edit state.

Context

PATCH or MIXER.

Surface

Strip, detail, utility, modal, or browser.

Focus

Region plus row/control coordinates.

Mode

Navigate, adjust, choose, toggle, or multi-select.

Origin

Remembered row for a precise return path.

The inferred state model is hierarchical, not screen-based. A “screen” is the projection of context + surface + focus + mode + origin.

This explains why the same Detail shell can represent an instrument, an effect, or a sample without becoming three unrelated interaction systems.

06 / Figma gaps

What the file does not settle

These are ambiguities inside the Figma evidence itself. They should be resolved in the design before anyone treats the interaction model as implementation-ready.

Q01 / SELECTOR CHANGE

Is unmodified Left/Right navigation or mutation?

Patch rows say “L/R:change,” while the interaction map says the unmodified D-pad moves focus and Edit+Left/Right performs fine adjustment. The selector’s direct-change rule needs one unambiguous binding.

Q02 / SAMPLE PREVIEW

What physical control is “X”?

The Sample Browser note says “X previews only while held,” but the hardware legend defines only Select, Start, Edit, Shift, and D-pad. The visible footer also omits preview. This action is not grounded to the declared controller vocabulary.

Q03 / MULTI-SELECT

What can a multi-selection do?

Select enters multi-select mode, but the map and Mixer frame do not show selection accumulation, range rules, batch operations, cancellation, or visual examples.

Q04 / PROTOTYPE COVERAGE

Which transitions are executable in Figma?

The inspected screen and state nodes contain no prototype reactions. Flow is communicated through annotations, labels, and the interaction map, so click-through behavior cannot confirm edge cases.
